# تقرير الترقية — الوسائط الحقيقية في THE CINEMA INDEX
**«Vidstreams» upgrade report · 2026-10-11 · فرع `arena/c7cba6a4-cleofinal3`**

## ملاحظة الهوية (مهم)

لم يُعثر على أي مشروع باسم «Vidstreams» في هذا المستودع ولا في حساب `nssm11`
(بحث في الأسماء والكود). الموقع السينمائي الوحيد القائم هو **THE CINEMA INDEX**
(`/cinema-index`)، ونفّذت الترقية فيه مع الحفاظ الكامل على تصميمه وبياناته ومساراته.
إن كنت تقصد مشروعًا آخر، انقل الفروع المقفلة: طبقة الوسائط كاملة تحت
`src/lib/media/` + `src/data/sources.ts` + `public/subtitles/`.

---

## 1. التكاملات المضافة (integrations)

| التكامل | النوع | الحالة |
|---|---|---|
| **Wikimedia Commons API** (`providers/commons.ts`) | مضيف فيديو + videoinfo/derivatives + بحث | **نشط ومُختبَر** — المصدر الوحيد للتشغيل والتنزيل |
| **TVmaze API** (`providers/tvmaze.ts`) | بيانات وصفية للمسلسلات (بلا مفتاح) | **نشط ومُختبَر** (طابق breaking-bad وبحث عام) — غير مطابَق للصامتين، ويُقال ذلك صراحة |
| **TMDB API** (`providers/tmdb.ts`) | اكتشاف/بيانات وصفية — ليس مضيف فيديو | **مُفعَّل بشرط المفتاح** — غير مُفعَّل هنا (لا مفتاح)، والواجهة تعرض ذلك بصدق |
| **OpenSubtitles-style discovery** (`src/lib/subtitles/`) | اكتشاف ترجمات بالمعرّفات الصحيحة + SRT↔VTT | **وحدة التحويل والتحميل مُفعَّلة**؛ الاتصال الخارجي يتطلب `OPEN_SUBTITLES_API_KEY` |
| **نظام التحقق** (`src/lib/media/verify.ts`) | فحص مباشر (HEAD→Range) + كاش TTL + إعادة فحص كل 7 أيام | **نشط ومُختبَر** (اختبارات وحدة + DOM) |
| **الأتمتة** (`scripts/sync-catalog.mjs`) | مزامنة الكتالوج: كومنز + TVmaze + TMDB + تقرير انحراف | **مُنفَّذ**؛ يعمل على جهاز بشبكة مفتوحة (`npm run sync`) |
| **التنزيلات** (`src/lib/media/downloads.ts`) | صفوف تنزيل من ملفات المزوّد (حجم حقيقي/تقدير مُعلَّم) | **نشط ومُختبَر** |

الإنترنت أرشيف **محذوف تمامًا** (اختبار آلي يمنع أي سلسلة `archive.org` في المصدر).
لا DRM، لا تجاوز حماية، لا بيانات وهمية.

## 2. متغيرات البيئة (env)

| المتغير | إلزامي؟ | الاستخدام |
|---|---|---|
| `VITE_TMDB_API_KEY` / `TMDB_API_KEY` | اختياري | تفعيل اكتشاف TMDB (بيانات وصفية فقط) |
| `OPEN_SUBTITLES_API_KEY` | اختياري | الاتصال بفهرس ترجمات OpenSubtitles-Style |
| — | لا شيء إلزامي | المشغّل والتنزيل والتحقق تعمل كاملة بلا مفاتيح (كومنز مفتوح) |

المفاتيح تبقى في متغيرات بيئة جانب الخادم/البناء — لا تُطبع في الواجهة.

## 4. المشغّل — ما أُضيف دون تغيير الهوية

منصّة العرض التحريرية نفسها (حبر/ورق، RTL، الجداول): +
- **اختيار الجودة** من سُلّم المزوّد الحقيقي (أصلي + 1080p/480p/240p… بالأبعاد الفعلية).
- **ترجمة عربية**: تفعيل/إيقاف/تبديل، اتجاه RTL داخل المشغّل، والأصل مُصرَّح.
- **لوحة التنزيل**: روابط ملفات حقيقية، أحجام حقيقية للأصل وتقديرية مُعلَّمة للنسخ.
- **لوحة حالة المصدر**: الملف/المزوّد/الترخيص/نتيجة الفحص المباشر/تاريخه.
- **حالات فشل صريحة**: خطأ تشغيل + إعادة محاولة + صفحة المصدر — بلا أزرار وهمية.

## 6. الترجمة العربية — بصدق

- `nosferatu-ar.srt`: **240 جملة**، ترجمة عربية كاملة أُنتجت لهذه الطبعة من الترجمة
  الإنجليزية المرخّصة على كومنز — **بنفس التوقيتات حرفيًا** (اختبار يثبته).
- مُصرَّح به في المشغّل وفي `src/data/subtitles.ts`. الإنجليزية متاحة عبر «صفحة
  المزوّد فقط» بلا ملف مزيّف.
- باقي الأعمال: رسالة غياب صريحة. **صفر ترجمات مخترعة.**

## 7. القيود المتبقية (limitations — صريحة)

1. **شبكة بيئة العمل**: متصفح العرض التجريبي هنا لا يسمح له إلا بمضيفات GitHub/npm —
   لذا يُظهر الفحص المباشر «فشل التحقق» داخل العرض التجريبي، بينما التشغيل
   الفعلي ينجح على أي متصفح بشبكة عادية (الروابط مُتحقَّق منها عبر واجهة المزوّد).
   سكربت `npm run sync` كذلك يحتاج شبكة مفتوحة.
2. **TMDB وOpenSubtitles** بحاجة مفاتيح env — بدونها تقول الواجهة «غير مُفعَّل».
3. **ترجمة واحدة عربية** فقط مرفوعة حاليًا (نوسفيراتو) — الإنتاج البشري الموثوق
   بطيء عن قصد؛ الوحدة جاهزة لاستقبال المزيد.
4. ملفات نانوك/بوتيمكين/كاليجاري منخفضة الدقة نسبيًا (240p-360p) — هكذا هي
   النسخ المتاحة قانونيًا؛ نُظهر الأبعاد الحقيقية ولا ندّعي HD.
5. إثراء TVmaze غير مطابَق للأعمال الصامتة (غير موجودة في قاعدة TVmaze) —
   مُشار إليه بصدق في الواجهة.
6. الصفحة العربية الثالثة لـ «مصّاصو الدماء»: العنوان الأصلي مُصحَّح إلى
   «Le Cryptogramme rouge» (اسم الملف الحقيقي).
